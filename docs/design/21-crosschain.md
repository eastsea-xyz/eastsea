# 21. 다른 체인과의 교환: 원자적 스왑과 라이트 클라이언트 브리지 (2026-09-29)

근거: [crosschain-2026.md](../research/crosschain-2026.md), [bridge-security-2026.md](../research/bridge-security-2026.md), [chain-bls-2026.md](../research/chain-bls-2026.md). 원칙은 [12-launch-plan.md](12-launch-plan.md)와 같다: 남의 자산을 맡지 않는다(수탁형 브리지 금지), 관리자 키 없음, 수수료 0.

## 한 문장
> 다른 체인과는 **수탁 없이** 잇는다. 처음에는 원자적 스왑(HTLC), 다음에 상대 체인이 우리 위원회 서명과 영지식 증명을 **둘 다** 직접 검증하는 라이트 클라이언트 브리지.

## 어느 체인과 되나

| 체인 | 원자적 스왑 | 우리 인증서 검증(BLS12-381) | 방식 |
|---|---|---|---|
| 이더리움, BNB, Base, Arbitrum, OP, Polygon | 가능 | 가능(EIP-2537/BEP-439, 페어링 2개 약 10만 가스) | 라이트 클라이언트. 이더리움 코드 재사용 |
| Sui | 가능 | 가능(`bls12381_min_sig_verify`: 우리와 같은 MinSig) | 라이트 클라이언트 |
| Aptos, NEAR, TON | 가능 | 가능 | 라이트 클라이언트 |
| 솔라나 | 가능 | 시스템콜 있음(확인 필요), BN254 Groth16 가능 | Jolt 증명을 Groth16으로 감싸 검증 |
| Avalanche C-Chain, Tron | 가능 | 안 됨 | 원자적 스왑만 |
| 비트코인 | 가능(원조) | 안 됨 | 원자적 스왑만 |

## 단계

| 단계 | 내용 | 시점 |
|---|---|---|
| 1 | 원자적 스왑: DBLN↔ETH·SOL·BTC. 해시 잠금 + 시간 잠금, 비대칭 시간 초과(환불 ≥ 2 × 청구 + 4시간, 컨트랙트가 강제). 교환 상대는 누구나 될 수 있는 메이커 봇 | 메인넷 후 첫 확장 |
| 2 | 이더리움 라이트 클라이언트 브리지(양방향). EVM 체인·L2로 복제 | 2단계 |
| 3 | 솔라나(영지식 경로), Sui·Aptos(수요에 따라) | 3단계 |
| 4 | USDC는 Circle CCTP(소각·발행) 참여를 추진해 잠긴 잔액 자체를 줄임 | 가능할 때 |

## 보안 요구 (첫날부터)

| 요구 | 내용 | 이유 |
|---|---|---|
| **이중 검증** | 메시지는 위원회 임계 BLS 서명 **과** Jolt 블록 증명(상대 체인에서는 Groth16으로 감싼 것)이 **둘 다** 통과해야 실행 | 키 탈취(Ronin, Harmony)와 검증 버그(Wormhole, BNB 증명 위조)가 동시에 일어나야만 뚫림 |
| **위원회 독립도에 묶인 한도** | 창업자 예비 키가 위원회에 있는 동안: 브리지 총 한도를 작게, 큰 출금은 24시간 이상 대기. 독립 위원이 채워질수록 한도가 늘어남(체인 상태에서 계산) | 부트스트랩 동안 창업자 Mac이 정족수를 쥘 수 있음 |
| **시간당 출금 상한** | 토큰 버킷: 시간당 총 잠금액의 1% 이하 | 뚫려도 손실 상한 |
| **자산별 격리** | 자산마다 금고와 한도 분리. 비표준 토큰(리베이스, 전송 수수료)은 별도 | 한 자산 문제가 전체로 번지지 않음 |
| **불변 컨트랙트** | 업그레이드 키 없음. 필요하면 새 브리지를 배포하고 사용자가 옮김 | Nomad식 초기화·업그레이드 사고 |
| **누구나 멈출 수 있는 불변식 차단** | "발행량 > 잠금량" 같은 불변식 위반을 증거로 제출하면 **누구나** 브리지를 멈춤. 운영자 정지 키는 두지 않음 | 관리자 없이 멈출 수단 |
| **비상 탈출** | 우리 체인이 7일 이상 멈추면 사용자가 상대 체인에서 마지막 확정 상태 증명으로 원금을 직접 회수 | 수탁 없이 자금 보호 |
| **재사용 방지** | 서명 대상에 출발·도착 체인 ID, 브리지 주소, 고유 논스, 그룹 번호 포함. 0 루트는 항상 거부 | 재생·포크 공격 |
| **원자적 스왑 앞지르기** | 청구 공개(프리이미지)가 멤풀에서 앞지르기되지 않게 순서 보장. 이후 어댑터 서명 방식 검토 | HTLC 고유 공격 |

- 제안됐지만 받지 않은 것: 운영자가 쥔 정지(pause) 키와 우리가 운영하는 별도 감시 네트워크. 관리자 키 없는 원칙과 충돌하고, 멈추는 권한이 새 공격 표적이 된다. 대신 위의 "누구나 멈출 수 있는 불변식 차단"과 시간 지연을 쓴다.

## 레드팀 반영 (Codex, 2026-09-29)

지적 12건(Critical 3, High 7, Medium 2)을 모두 받았다. 위 표의 규칙은 아래 내용으로 **보강·대체**된다.

| 지적 | 등급 | 바뀐 규칙 |
|---|---|---|
| BLS 정족수를 쥐면 실행 증명(ZK)만으로는 막지 못함 | Critical | 역할을 나눈다. BLS = 최종성 권한, ZK = 그 헤더가 커밋한 메시지의 포함과 실행 결과. ZK는 **정족수 탈취를 막는 층으로 세지 않는다**. 정족수 탈취의 방어는 한도·지연·세대 검사다 |
| BLS와 ZK의 공개 입력이 묶여 있지 않음 | Critical | 두 검증이 **같은 공개 입력 묶음**을 쓴다: 출발·도착 체인 ID, 브리지 주소, 위원회·그룹 ID, **키 세대**, 블록 높이, 블록 해시, state root, message root, 메시지 논스. 하나라도 다르면 실행 거부. 양쪽이 같은 입력을 검증하는 테스트 벡터가 배포 조건 |
| 창업자 정족수 동안 Ronin·Harmony형 키 탈취 | Critical | 창업자 예비 키가 위원회에 있는 동안의 **최대 한도와 출금 지연을 컨트랙트 상수로 고정**(자동 상향 없음). 독립 운영자 판정이 체인에서 검증 가능해진 뒤에만 새 브리지 배포로 한도를 올린다 |
| 같은 공개키로 reshare를 거듭하면 share가 누적될 수 있음 | High | 인증서와 브리지 상태에 **키 세대·handoff 높이**를 넣는다. 브리지는 허용된 세대와 단조 증가 높이만 받는다. 이전 share 폐기를 reshare 절차의 필수 단계로 둔다 |
| Jolt→Groth16 래퍼가 아직 없음 | High | 래퍼 회로의 공개 입력·검증 대상·신뢰 설정 명세와 독립 감사가 **2·3단계 출시 차단 조건**이다. 그 전에는 이중 검증을 완성된 방어로 계산하지 않는다 |
| 명목상 검증자를 늘려 한도를 올리는 Sybil | High | 한도는 검증자 수가 아니라 **운영자 단위**(운영자당 좌석 상한과 같은 기준)로 센다. 확인 안 된 독립성은 0으로 친다 |
| 누구나 멈추는 기능을 거짓 증거로 남용 | High | 확정 체크포인트의 root와 포함 증명으로 **컨트랙트가 직접 검증한** 불변식 위반만 인정한다. 제출자는 담보를 걸고, 거짓이면 몰수한다. 위반이 확인된 자산·방향만 멈춘다 |
| 비상 탈출과 정상 출금의 이중 지급 | High | 탈출이 시작되면 해당 브리지를 원자적으로 동결하고 단일 스냅샷을 정산 기준으로 고정한다. 청구마다 nullifier를 기록한다 |
| 7일 기준이 모호함 | Medium | 기준 = "마지막으로 검증된 finalized header 이후 7일". 헤더 한 개가 도착하면 초기화되며 누구나 제출할 수 있다 |
| 프리이미지 앞지르기 | High | HTLC는 만들 때 **수취인 주소를 고정**한다. 제3자가 프리이미지로 청구해도 돈은 고정된 수취인에게만 간다. 어댑터 서명은 그 위의 개선 |
| 한 가지 시간 공식으로는 비트코인 재구성·수수료 급등을 못 막음 | High | 체인 쌍마다 확인 수, 높이 기반 잠금, 수수료 지연 버퍼를 따로 정한다. 비트코인은 6확인과 넉넉한 버퍼를 두고, Aether 환불 기한을 그 뒤에 둔다 |
| 메이커가 한쪽만 잠그고 사라져 자금을 묶음 | Medium | 락업 순서는 메이커가 먼저 잠근다(사용자는 메이커 잠금이 확정된 뒤 잠금). 메이커 호가에는 보증금과 미이행 기록을 둔다 |
| Multichain형 운영 중앙화 | Medium | 독립도 산정에 키 보관, 백업, 복구, 서명 인프라의 지배 주체까지 포함한다 |
