# 조코헌트(JocoHunt) 선정 기준과 1등 전략 (2026-10-04 조사)

출처: 조코헌트 사이트를 브라우저로 직접 읽음(jocohunt.com 랭킹·자주 묻는 질문·소개 페이지, 2026-10-04 19시대). 조코딩이 운영하는 한국 인디 빌더용 프로덕트 런칭 커뮤니티(Product Hunt형, Open-Launch 오픈소스 기반).

## 선정 기준 (사이트 문구 그대로 요약)
- **주간 1등 = 한 주(KST 일요일~토요일 23:59) 동안 받은 순수 득표순.** 모든 표는 1표로 같다. 씨앗(커뮤니티 크레딧)은 투표·랭킹·1등에 전혀 영향이 없다.
- **투표 자격**: GitHub 로그인만 가능, 그리고 GitHub 계정 7일 이상 + 공개 커밋 1회 이상인 회원만 투표 가능. 자기 프로덕트 투표는 집계되지 않음. 의심 패턴은 운영자가 검토.
- **보상**: 주간 1등은 일요일 18:00 조코딩 채널 라이브와 조코레터(뉴스레터)에 소개, 영구 'Featured on JocoHunt' 뱃지, 메이커 프로필 1등 횟수, 베스트(리더보드) 영구 기록. 2~5위는 5표 이상이면 조코레터에 소개.
- **카테고리별 1등**은 별도(대표 카테고리 1곳). 카테고리 14개: AI 도구, 개발자 도구, 디자인, 노코드, 생산성, 마케팅, B2B SaaS, 웹 서비스, 모바일 앱, 크리에이터 도구, 자동화, 교육, 게임, 기타.
- 출시 무료, **예약 출시** 가능(같은 날 출시작과 함께 공개), 동일 프로덕트 중복 출시 불가(큰 업데이트는 changelog로 재노출).
- 구조화 피드백(UX·가격·아이디어 검증·네이밍·마케팅·GTM 중 메이커가 선택), 피드백 요청권(씨앗으로 72시간 노출: 상세 상단 고정 질문, 홈 '피드백 기다리는 제품', 커뮤니티 피드).

## 지금 경쟁 강도 (관찰)
41주차(10월 4일~10일) 첫날 기준 출시 3개, 1위가 **1표**. 사이트가 막 열린 단계라 진정성 있는 표 10~20개면 1등 가능성이 높다(주마다 다르므로 출시 직전 그 주 리더보드를 다시 본다).

## 1등 하려면 (정직한 방법만)
1. **일요일 0시(KST)에 예약 출시** → 7일을 온전히 쓴다. 토요일 출시는 하루만 경쟁.
2. **투표할 수 있는 사람을 미리 확보**: GitHub 7일·커밋 1회 조건 때문에 당일 가입자는 못 찍는다. 개발자 지인, 우리 GitHub 조직(`eastsea-xyz`) 관심자, 개발자 커뮤니티에 출시 공지. "투표 부탁"보다 "써 보고 피드백 주세요"가 규칙 위험이 적다.
3. **페이지 완성도**: 한 줄 소개는 사람이 얻는 것(H1·H2 계열, 교정본), 스크린샷·갤러리, 60초 영상(데모 문서의 영상 1), 메이커 첫 댓글(만든 이유·지금 상태·받고 싶은 피드백), 구조화 피드백 카테고리 선택(UX·네이밍·GTM 권장).
4. **모든 댓글에 빠르게 답한다**(주중 내내). 다른 메이커 제품에도 성실한 피드백 → 씨앗을 모아 피드백 요청권(72시간 노출)으로 쓴다(투표에는 영향 없지만 노출이 늘어 정상 투표로 이어진다).
5. **카테고리**: 대표 '개발자 도구'(에이전트 지갑·노드) 또는 'AI 도구'(MCP 지갑). 카테고리 1등을 따로 노릴 수 있다.
6. **하지 말 것**: 부계정·표 구매·표 교환 모임(운영자 검토 대상이고 브랜드 신뢰를 깎는다), 코인 가격·수익·상장 이야기(법률 메모 3.6절, 홍보 계획 v2와 같은 선).

## 우리 쪽 조건 (출시 전에 필요한 것)
- **써 볼 수 있는 것이 있어야 한다.** 지금 앱과 소스는 비공개라 방문자가 할 수 있는 게 없다. 후보: (a) 테스트넷 공개 베타 앱 배포(공증 DMG, 맥 전용, 테스트넷 코인 가치 없음 명시), (b) 소스 공개(`eastsea-xyz/eastsea`), (c) 에이전트 지갑 CLI(MCP)만 먼저.
- **홍보 계획 v2의 공개 조건과 같다**: 상표 출원 접수증, 변호사 검토(첫 글·사이트·면책), 사이트 호스팅. 조코헌트 출시도 공개 홍보이므로 이 조건을 먼저 채운다.
- 가상자산 관련 제품이라는 점: 소개는 지갑·노드 기능으로, 코인은 "테스트넷 코인은 가치 없음, DBLN 판매 없음"만.
- GitHub 로그인이 필요하므로 창업자 GitHub 계정으로 메이커 등록(팀원 추가 가능).

## 권장 일정
조건(상표·변호사·사이트·써 볼 수 있는 베타)이 채워진 주의 **일요일 0시 예약 출시**. 그 전 1~2주 동안 조코헌트에서 다른 메이커에게 피드백을 남겨 씨앗과 관계를 쌓는다(창업자 계정, 공시 포함).
