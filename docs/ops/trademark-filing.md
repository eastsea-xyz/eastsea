# 상표 출원 절차 (최소 비용, 직접 출원) — 2026-09-29

근거: [trademark-2026.md](../research/trademark-2026.md), [eastsea-2026.md](../research/eastsea-2026.md), [stablecoins-2026.md](../research/stablecoins-2026.md). 금액은 조사 보고서 기준이므로 **출원 직전에 특허로 수수료 계산기로 다시 확인**한다. 법률 자문이 아니다.

## 원칙
- 변리사 없이 **직접 출원**한다(대행료 25~45만 원/류 절약).
- 분류는 **9류, 36류 두 개만**. 42류·35류는 여유가 생기면 추가.
- **우선심사는 신청하지 않는다**(분류당 약 16만 원). 포크나 선점자가 실제로 나타날 때만 쓴다.
- 등록료는 **등록결정이 난 뒤에** 낸다. 지금 내는 돈은 출원료뿐이다.
- 출원이 코드 공개보다 **먼저**여야 한다(선출원주의).

## 지정상품 (고시명칭에서 고른다)
특허로 전자출원의 **"유사상품코드/고시명칭 검색"** 에서 아래 키워드로 찾아 **고시명칭이 있는 것만** 고른다(고시 명칭이면 관납료가 낮다). 여기 적은 문구를 그대로 쓰지 말고 검색 결과의 공식 명칭을 쓴다.
- 9류 검색어: 컴퓨터 소프트웨어, 모바일 앱, 다운로드 가능한 전자지갑, 암호화 키 관리 프로그램, 브라우저 확장 프로그램, 블록체인
- 36류 검색어: 가상자산 관련 금융, 전자지갑을 통한 결제·송금, 블록체인 기반 금융 거래

## 출원 전 무료 검색 (직접)
1. KIPRIS(kipris.or.kr) 상표 검색: `EASTSEA`, `이스트씨`, `EAST SEA`, `동해`를 9류·36류에서 검색. 결과 화면을 저장해 이 폴더에 둔다.
2. USPTO Trademark Search, EUIPO eSearch, WIPO Global Brand Database에서도 `EASTSEA`를 확인(해외 출원 전).
3. 겹치는 상표가 있으면 출원하지 말고 이 문서 맨 아래 "막혔을 때"를 본다.

## 대표님이 하실 일 (제가 대신할 수 없는 부분)
1. 특허로(patent.go.kr) 로그인. 공동인증서 또는 간편인증이 필요하다(법인이면 법인 인증서).
2. 위 표장·분류·지정상품으로 전자출원서를 작성하고 결제(약 9.2만 원).
3. 출원번호와 접수증을 받아 이 저장소 `docs/ops/` 에 사본을 남긴다(개인정보는 가린다).
4. 출원이 끝나면 저에게 알려 주시면 TRADEMARKS.md의 "출원 중"을 출원번호로 바꾸고 코드 공개를 진행한다.

## 출원 뒤
- **등록 표시:** 등록되기 전에는 `™`만 쓰고 `®`는 쓰지 않는다.
- **의견제출통지서(거절이유)가 오면** 기한(보통 2개월) 안에 답한다. 직접 의견서를 쓰면 무료다. 어려우면 그때만 변리사(건당 15~30만 원)를 쓴다.
- **해외 출원:** 한국 출원일에서 **6개월 안에** 하면 한국 날짜가 인정된다(조약 우선권). 미국은 현지 변호사가 필수라 가장 비싸다. 자금이 생길 때까지 미룬다.
- **무료 도움:** 대한변리사회·특허청 지식재산 기관의 무료 상담(가능 여부와 조건은 직접 확인).
