# Aether 0.6.0 (testnet)

Aether 0.6.0 for macOS (Apple silicon), signed by Pipln and notarized by Apple.

Drag Aether to Applications. The app is a wallet and, with the switch on, a node that verifies every block on this Mac. It connects to the Aether testnet (test tokens have no value).

Updates arrive automatically (Aether ▸ Check for Updates…).

0.6.0: protocol 2 (the testnet has activated it: update to keep following the chain): a proof market where Macs prove blocks on their GPU for rewards, halving issuance, a bounded device registrar. The app fits an iPhone-wide window, and aether:// links from web pages open in the window you have. The built-in node answers browser dApps directly (CORS, eth_call). New: Aether Wallet browser extension for Chrome, Edge, Brave and Arc (aether-extension-0.1.0.zip below; chrome://extensions > Developer mode > Load unpacked). It works without this app: the key is made in the browser and encrypted with your password.
