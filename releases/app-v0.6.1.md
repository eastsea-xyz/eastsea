# Aether 0.6.1 (testnet)

Aether 0.6.1 for macOS (Apple silicon), signed by Pipln and notarized by Apple.

Drag Aether to Applications. The app is a wallet and, with the switch on, a node that verifies every block on this Mac. It connects to the Aether testnet (test tokens have no value).

Updates arrive automatically (Aether ▸ Check for Updates…).

0.6.1: first launch asks you to accept the terms (experimental testnet software, used at your own risk) and says how mainnet will launch: no token sale, no founder share, and no block rewards until 16 different operators vote. Once your node has caught up, Aether asks once whether this Mac should join as a voting node, and shows why a registration failed and how close the Mac is to being drawn. Updates now install right away and relaunch the app, so a Mac that keeps Aether running follows protocol upgrades; the Network page shows the version, when updates were last checked, and a Check for Updates button. The Developer switch moved to the toolbar.
