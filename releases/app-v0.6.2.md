# Aether 0.6.2 (testnet)

Aether 0.6.2 for macOS (Apple silicon), signed by Pipln and notarized by Apple.

Drag Aether to Applications. The app is a wallet and, with the switch on, a node that verifies every block on this Mac. It connects to the Aether testnet (test tokens have no value).

Updates arrive automatically (Aether ▸ Check for Updates…).

0.6.2: the Home page shows at a glance that your node is working and what it has earned (test AETH actually received, with a burst when a reward lands); new loading animations; the agent's Claude Code/Codex plugin finds the network by itself and gains read-only DEX tools (pools, token info, quotes). The node knows protocol 3 (Macs with a day of uptime join the voting set instead of replacing members), which the testnet will activate soon: this update keeps your node following the chain.
