# Aether 0.6.6 (testnet)

Aether 0.6.6 for macOS (Apple silicon), signed by Pipln and notarized by Apple.

Drag Aether to Applications. The app is a wallet and, with the switch on, a node that verifies every block on this Mac. It connects to the Aether testnet (test tokens have no value).

Updates arrive automatically (Aether ▸ Check for Updates…).

Faster catch-up (a Mac that was off jumps to the network's tip in seconds instead of replaying every block), self-healing (the node restarts itself and recovers from disk errors), and resource limits (memory, CPU and disk caps for proving, with settings in the app).
