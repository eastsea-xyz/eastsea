# EastSea 0.7.4.2 (testnet)

EastSea 0.7.4.2 for macOS (Apple silicon), signed by Pipln and notarized by Apple.

Drag the app to Applications. The app is a wallet and, with the switch on, a node that verifies every block on this Mac. It connects to the EastSea testnet (test tokens have no value).

Updates arrive automatically (EastSea ▸ Check for Updates…).

This update keeps blocks flowing under load: public reads no longer stall block voting, saving blocks runs on its own worker, and a node closes its database cleanly when it stops, so restarts take seconds instead of minutes. The explorer is calmer and fully localized.
